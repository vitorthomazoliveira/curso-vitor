## 📚 Sobre o projeto

Landing page informativa do minicurso **"Introdução ao Git e GitHub: Explorando o controle de versão"**, desenvolvido no **Projeto de Curricularização da Extensão** da **FEMA** (Fundação Educacional do Município de Assis) 🏛️.

A página apresenta os conceitos do minicurso de forma visual e interativa, para ingressantes de tecnologia que querem aprender versionamento de código.

---

## 🎯 Sobre o minicurso

### 🏁 Objetivo
Apresentar os conceitos básicos de controle de versão com Git e GitHub, mostrando na prática como:
- 📁 criar repositórios
- 💾 realizar commits
- ☁️ enviar alterações para o GitHub
- 🤝 colaborar em projetos simples

### 👥 Público-alvo
Alunos **iniciantes** da área de tecnologia que querem aprender os fundamentos de versionamento e colaboração em projetos de software.

### 🧪 Metodologia
- 🖼️ Slides de apoio para introduzir os conceitos
- 🎬 Vídeos curtos sobre GitHub
- 📽️ Demonstração ao vivo com projetor
- 🛠️ Projeto simples para praticar os comandos
- 💻 Alunos acompanhando as atividades nos próprios computadores

### 🗂️ Conteúdo programático

| 🔢 Parte | 📌 Tema | 📝 Tópicos |
|:---:|---|---|
| 1️⃣ | 🌍 **Introdução** | O que é controle de versão, problemas de não versionar, o que é Git e GitHub, aplicações no mercado |
| 2️⃣ | 🎬 **Demonstração conceitual** | Vídeos introdutórios, relação entre Git e GitHub, fluxo básico de trabalho |
| 3️⃣ | 🛠️ **Prática guiada** | `git init` · `git status` · `git add` · `git commit` · `git log` · repositório remoto · `git push` · `git pull` |
| 4️⃣ | 🎉 **Encerramento** | Revisão dos conceitos, dúvidas e materiais complementares |

### 🏆 Resultados esperados
Ao final, você será capaz de:
- ✅ Compreender o conceito de controle de versão
- ✅ Utilizar os principais comandos do Git
- ✅ Criar e gerenciar um repositório no GitHub
- ✅ Publicar e atualizar projetos com Git e GitHub

### 🎒 O que levar
- 🐙 Conta criada no [GitHub](https://github.com/signup)
- 🔧 [Git](https://git-scm.com/downloads) instalado
- 📝 Um editor de código, como o [VS Code](https://code.visualstudio.com/)
- 🌐 Computador com acesso à internet

## 🖥️ Sobre a landing page

Site estático feito só com **HTML, CSS e JavaScript** puros, sem frameworks nem etapa de build ⚡.

### 🧩 Seções
| | Seção | O que tem |
|:---:|---|---|
| 🏠 | **Topo** | Apresentação com terminal animado |
| 🤔 | **Por que versionar** | Comparação entre trabalhar com e sem controle de versão |
| ⚔️ | **Git vs GitHub** | Cartões interativos que explicam a diferença |
| 🔄 | **Fluxo de trabalho** | Working Directory → Staging → Local → Remote |
| ⌨️ | **Comandos** | Simulador interativo e tabela de referência rápida |
| ☁️ | **Local e remoto** | `remote`, `push`, `pull` e `clone` |
| 📈 | **Mercado** | Relevância do Git na indústria |
| 📅 | **Programação** | Conteúdo, resultados esperados e checklist |
| 👩‍💻 | **Equipe** | Quem produziu, com links de GitHub e LinkedIn |

### ✨ Recursos
- 📱 Layout responsivo (computador, tablet e celular)
- 🌙 Tema escuro com as cores do Git 🟠 e do GitHub 🔵
- 🖱️ Simulador de terminal com a saída de 11 comandos Git
- 🎞️ Animações ao rolar a página, respeitando a preferência de movimento reduzido
- ☑️ Checklist que guarda o progresso no navegador
- ♿ Navegação acessível por teclado

### 📂 Estrutura do projeto

```
📦 LP-Git
 ┣ 📜 index.html   → estrutura e conteúdo
 ┣ 🎨 style.css    → estilos e responsividade
 ┣ ⚙️ script.js    → interações (terminal, simulador, animações)
 ┗ 📖 README.md
```

### ▶️ Como executar
Não precisa instalar nada 🎉. É só abrir o `index.html` no navegador.

Para servir localmente (opcional) 🧪:

```bash
python -m http.server 8000
```

Depois acesse 👉 `http://localhost:8000`

### 🌐 Publicar no GitHub Pages
1. ⚙️ No repositório, abra **Settings → Pages**
2. 🌿 Em **Source**, escolha a branch `main` e a pasta `/ (root)`
3. 💾 Salve e aguarde um instante
4. 🔗 O site ficará em `https://<usuario>.github.io/<repositorio>/`
